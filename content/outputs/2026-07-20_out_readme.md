# 05_Outputs (成果物・完成品格納エリア)

AIチーム（Claude Code, Codex, Antigravity）およびQuQuLa89が作成した最終成果物（Output）を格納するフォルダです。

## 格納する成果物の例
- **完成した設計書・決定ログ (ADR)**
- **Zenn / Qiita 投稿用記事**
- **各種自動化スクリプト・ツール**
- **プロジェクト完了報告書**

## 運用ルール
- 開発やリサーチの過程で生じたメモではなく、「完成品・活用可能な成果物」のみをここに配置します。
- メモが実際にどれだけの成果（Output）を生んだかを可視化するための重要エリアです。
